# CPET - Portal de Acompanhamento Acadêmico - Acesso [clique aqui](https://jadilson-tech.github.io/site_do_marcos/ )

Projeto acadêmico desenvolvido em HTML com foco em estrutura semântica, organização de conteúdo e conceitos básicos de desenvolvimento web.

##  Objetivo

O objetivo deste projeto é demonstrar a construção de uma página web responsiva utilizando HTML5 semântico, aplicando conceitos de:

- Estruturação semântica;
- Organização de conteúdo;
- Inserção de imagens;
- Links externos;
- Hierarquia de títulos;
- Listas ordenadas e não ordenadas;
- Publicação com GitHub Pages.

---

##  Tecnologias Utilizadas

- HTML5
- Git
- GitHub
- GitHub Pages

---

##  Funcionalidades

- Página acadêmica estruturada;
- Área de apresentação do aluno;
- Imagem ilustrativa centralizada;
- Sessão de evolução do curso;
- Link externo para plataforma CPET;
- Análise da aplicação;
- Estrutura semântica moderna.

---

##  Perfil dos Usuários

O sistema foi pensado para:

- Estudantes;
- Tutores;
- Professores;
- Administradores acadêmicos.
